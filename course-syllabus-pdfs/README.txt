HOW TO ADD DOWNLOADABLE SYLLABUS PDFs
======================================

The "Download Syllabus" button in each course's popup links to a PDF
in this folder, named EXACTLY like the matching course-images file
but with a .pdf extension instead of .jpg — e.g.

cyber-security.jpg  (photo)   ->  cyber-security.pdf  (syllabus)
ai-engineering.jpg  (photo)   ->  ai-engineering.pdf   (syllabus)

See course-images/README.txt for the full list of course slugs.

If a PDF isn't uploaded yet for a course, the button will just show
a broken/404 link when clicked — nothing else on the page breaks.
