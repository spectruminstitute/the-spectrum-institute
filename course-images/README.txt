NOTES
-----
- File type can be .jpg, .jpeg, or .png — but if you use .png, also
  open courses.html and change that course's ".jpg" to ".png".
- Recommended size: at least 600x400px, landscape orientation
  (matches the banner shape on the card).
- If a photo is missing, the card just falls back to the plain
  icon design — nothing breaks.
